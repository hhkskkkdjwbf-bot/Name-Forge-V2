# Internationalization

28 interface languages are fully translated: the original 25 (`en fr es de it pt ar tr ja ko zh ru hi nl pl sv vi id th
el he cs ro da fi`) plus `uk` (Ukrainian), `bn` (Bengali) and `nb` (Norwegian Bokmål). The selector lists 82 languages;
the other 54 fall back to English text.

Existing languages, routes and URLs were preserved. The legacy code `no` is an alias of `nb`
(`canonicalLanguage` in `src/i18n/addedLanguages.ts`; stored settings are migrated on read).

## Where translations live

| Content | File |
|---------|------|
| Main dictionary (119 keys) | `i18n/index.ts` (25 languages) + `i18n/newLanguageTranslations.ts` (uk, bn, nb) |
| Shell, modals, collections, compare, my names, name details, studio, style labels | per-module files; uk/bn/nb in `i18n/addedLanguages.ts` |
| Generator titles and descriptions | `generatorTitles.ts`, `generatorContent.ts` (+ `addedGeneratorTitles.ts`, `addedGeneratorContent.ts`) |
| Editorial copy, SEO descriptions, FAQ | `localizedGeneratorMeta.ts`, `seoMetadata.ts`, `localizedFaq.ts` (+ `addedFaq.ts`) |
| Baby-name meanings and origins | `attestedNameTranslations.ts` (+ `addedNameTranslations.ts`) |
| Native phrase banks | `data/phraseBanks.ts` |
| Small tables embedded in views/components | the `uk/bn/nb` entries next to each `fi` entry |

`getTranslations` falls back to English for a missing key's whole language only; run `npm run audit:i18n` and `npm test`
to detect gaps. The regression suite checks every key of the main dictionary and every shared module for all 28
languages, placeholder consistency for the new languages, and translated meanings for all attested names.

## Language settings stay independent

Interface language, name language (`genLanguage`) and style are separate settings. The first visit picks the interface
language from the browser (`detectBrowserLanguage`); a saved choice always wins. RTL (`ar`, `he`) sets `dir="rtl"` on
the document and in the modals.

## Review status

All translations written for the project's additions (phrase banks, baby-name meanings, uk/bn/nb UI) are machine-written
by the assistant and **have not been reviewed by native speakers**. Have a native reviewer check them before publishing.
